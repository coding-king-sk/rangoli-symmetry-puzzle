# Rangoli v1.0.0

First playable release of Rangoli, a symmetry puzzle game for Android.

## What's in it

- **100 levels** across six chapters, one per symmetry type: vertical mirror,
  horizontal mirror, four-fold reflection, 90-degree rotation, diagonal mirror,
  and eight-fold radial.
- **Limited palette** - each colour has a tile budget, so the puzzle is about
  reading the symmetry correctly, not trial and error.
- **Star ratings** - three stars for a clean solve with no mistakes and no hints.
- **Hints and undo** for when a pattern gets stubborn.
- **Progress saved** locally with DataStore; chapters unlock as you clear levels.
- **Dashed symmetry axis** drawn on the board so it is always clear what the
  level is asking for.

## Under the hood

- 100% Kotlin, Jetpack Compose UI, Compose Canvas board rendering.
- Game rules live in a pure-Kotlin `domain` package with no Android imports,
  covered by unit tests.
- Levels are generated by colouring symmetry orbits, which makes every level
  symmetric by construction and solvable without a solver.

## Install

Download the attached APK and install it on any device running Android 7.0
(API 24) or newer. This is a debug-signed build, so you may need to allow
installation from unknown sources.
