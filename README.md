# Rangoli

A symmetry puzzle game for Android. Half of a rangoli pattern is given -- your job
is to complete the rest so the whole design is symmetric, using a palette where
every colour has a limited number of tiles.

100% Kotlin. Jetpack Compose. No game engine.

## How it plays

1. Part of the board is revealed as a clue, the rest is empty kolam dots.
2. Pick a colour from the palette (the badge shows how many tiles are left).
3. Tap empty cells to fill them. Tap a filled cell again to take the tile back.
4. Fill every required cell and the board is checked against the symmetry rule.
5. Clean solve with no mistakes and no hints earns three stars.

A dashed axis is always drawn on the board so you can see which symmetry is in
play.

## Chapters

| Chapter | Symmetry | Levels |
| --- | --- | --- |
| Aadha Aadha | Vertical mirror | 1-15 |
| Upar Neeche | Horizontal mirror | 16-30 |
| Chaar Kone | Four-fold reflection | 31-50 |
| Ghoomta Rangoli | 90-degree rotation | 51-70 |
| Tirchi Rekha | Diagonal mirror | 71-85 |
| Aath Pankhudi | Eight-fold radial | 86-100 |

Difficulty is shaped by four knobs rather than hand-authored levels: grid size
(5x5 up to 11x11), number of colours (2 to 5), palette tightness (spare tiles or
an exact fit), and the symmetry type itself.

## The core idea

Every cell belongs to an **orbit** -- the set of cells that must share its colour
under a given symmetry. Levels are generated by picking one colour per orbit:

```kotlin
val orbits = allCells.map { symmetry.orbitOf(it, size) }.distinct()
for (orbit in orbits) {
    val color = colors.random(random)
    orbit.forEach { solution[it] = color }
}
```

Because the pattern is built orbit by orbit, it is symmetric **by construction**.
There is no solver, no backtracking, and no solvability check anywhere in the
codebase. The revealed clue is the symmetry's fundamental domain, which is
guaranteed to contain a member of every orbit, so every hidden cell is always
deducible.

The palette then falls out for free: count the hidden cells of each colour.

## Architecture

```
app/src/main/java/com/rehan/rangoli/
├── domain/          pure Kotlin, zero Android imports
│   ├── Cell.kt
│   ├── PaintColor.kt
│   ├── SymmetryType.kt        orbit + fundamental-domain math
│   ├── Level.kt               Level + LevelSpec
│   ├── SymmetryValidator.kt   returns offending cells, not a boolean
│   ├── LevelGenerator.kt
│   └── LevelCatalog.kt        the 100 shipped levels
├── presentation/
│   └── GameController.kt      all mutable play state
├── ui/
│   ├── RangoliApp.kt
│   ├── game/                  GameScreen, RangoliCanvas, PaletteBar
│   ├── levels/LevelMapScreen.kt
│   └── theme/Theme.kt
└── data/ProgressStore.kt      DataStore star ratings
```

The `domain` package has no Android dependencies at all, which is why the rules
can be tested as plain JVM unit tests. Levels are generated deterministically
from the level index, so level 42 is the same puzzle on every device and no level
data needs to be shipped.

## Tests

```bash
gradle testDebugUnitTest
```

The suite locks down the parts that are easy to get subtly wrong:

- orbits partition the board with no overlaps, for every symmetry and grid size
- the odd-grid centre cell is its own only partner
- rotational symmetry is genuinely different from mirror symmetry
- the fundamental domain contains a member of every orbit, so no level can be
  undeducible
- all 100 shipped levels generate, are symmetric, and have a workable palette

## Build

Requires JDK 17.

```bash
gradle wrapper          # first time only, to create ./gradlew
./gradlew assembleDebug
```

The APK lands in `app/build/outputs/apk/debug/`.

CI runs the unit tests and builds a debug APK on every push. Pushing a `v*` tag
builds the APK and publishes it as a GitHub release.

## Roadmap

- Colourblind shape markers drawn on the board (glyphs are in the palette today)
- Per-cell fill and merge animations
- Sound effects and haptics
- Daily Rangoli with a streak counter
- Create mode: design your own symmetric rangoli and share it as an image
- Festival packs (Diwali, Pongal, Onam) with themed palettes

## Known limitations

- In-progress board state is not restored after the process is killed; only star
  ratings persist.
- Release builds are unsigned. Set up a signing config before publishing to Play.
